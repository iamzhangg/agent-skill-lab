# License gates

This is an engineering gate, not legal advice.

| Upstream state | Allowed default |
|---|---|
| Permissive license (MIT, BSD, Apache-2.0) | Adapt within the license; retain notices and identify changes |
| Copyleft license | Isolate and comply with redistribution/source obligations; do not claim the result is permissively licensed |
| Content license (for example CC BY) | Follow attribution and adaptation requirements; check code separately |
| No license or unclear ownership | Learn ideas and independently implement; do not copy text, code, templates, or assets |
| Trademark, personal style, or branded assets | Do not imply endorsement; prefer original naming and visual language |

Always inspect nested licenses and vendored assets. A repository-level license may not cover fonts, screenshots, model outputs, datasets, or third-party examples.
