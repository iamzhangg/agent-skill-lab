# Agent UX rubric

Review seven dimensions:

1. Expectations — capability, limits, cost, time, and data use are clear before commitment.
2. Observability — progress, tool use, source material, and current state are visible at the right level.
3. Control — users can steer, pause, edit, approve, cancel, and choose autonomy.
4. Verification — consequential outputs expose evidence, uncertainty, previews, or comparison.
5. Recovery — failure preserves work, explains next action, and supports retry or rollback.
6. Trust and safety — permissions and external effects match consequence; sensitive data is minimized.
7. Accessibility — state is not color-only; focus, labels, reading order, motion, and timing support diverse users.

Severity is `critical` when harm or irreversible action can occur without meaningful control, `high` for likely task failure or deception, `medium` for recoverable friction, and `low` for polish.
